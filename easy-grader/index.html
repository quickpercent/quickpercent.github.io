What Is an Easy Grader?

An Easy Grader, also called an EZ Grader, converts the number of wrong or correct answers into a percentage and letter grade. It is useful for teachers, students and anyone who needs to quickly grade a test.

How to Use the Easy Grader

Enter the total number of questions, enter the number of wrong answers, select a grading scale and calculate the result. You can also generate a complete EZ Grader chart for the selected test size.

Easy Grader Formula

Correct Answers = Total Questions − Wrong Answers

Percentage = (Correct Answers ÷ Total Questions) × 100

Frequently Asked Questions

What is an Easy Grader?

An Easy Grader is a grading tool that converts test answers into a percentage and letter grade.

Is Easy Grader the same as EZ Grader?

Yes. Easy Grader and EZ Grader are commonly used names for this type of grading calculator.

Can I use a custom grading scale?

Yes. Select Custom and enter the minimum percentage required for each letter grade.

Can I use half points?

Yes. Turn on Allow Half Points to calculate tests where partial answers count as half points.

Can I manually enter decimal wrong answers?

Yes. You can manually enter decimal values such as 0.5, 1.5, 2.5 or 3.5.

Can I choose percentage decimal precision?

Yes. Custom grading mode lets you display percentages with zero, one or two decimal places.

Can I print the EZ Grader chart?

Yes. Click Print Chart to print the grading chart or save it as a PDF using your browser.
