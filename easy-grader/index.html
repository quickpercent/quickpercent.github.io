Easy Grader

Easy Grader is a free online EZ Grader calculator for teachers, students and educators. Enter the number of questions and wrong answers to quickly calculate the correct answers, test percentage, letter grade and pass or fail result.

This Easy Grader Calculator also supports half-point answers, custom grading scales, plus and minus grades, percentage rounding and a complete EZ Grader chart.

Frequently Asked Questions

What is an Easy Grader?
An Easy Grader is a grading calculator that converts correct and incorrect test answers into a percentage and letter grade.
What is an EZ Grader?
EZ Grader is another common name for an easy grading calculator used to grade tests quickly.
Can I enter 2.5 wrong answers?
Yes. Enable Half-Point mode and you can enter values such as 0.5, 1.5, 2.5 and 3.5.
Can I use my own grading scale?
Yes. Select Custom grading scale and enter your minimum percentage for A, B, C, D and F.
Is Easy Grader free?
Yes. This Easy Grader calculator is free to use online.
